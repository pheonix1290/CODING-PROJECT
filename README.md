# 📂 Projects

## 🌍 1. Travel Kenya

A tourism website based around travelling to Kenya.

The website introduces different aspects of Kenya, including:

* 🦁 Wildlife
* 🏔️ Landscapes and nature
* 🌊 Beaches
* 🍛 Kenyan food
* 🛖 Culture
* 🌅 Sunsets

The project also includes navigation links to different sections of the website, including places to visit, food, contact and a gallery.

**Technologies:** HTML

📁 [`Travel Kenya`](./travel-kenya)

---

## 🍛 2. African Cuisine

A restaurant website based around African cuisine.

The website presents an imaginary family-owned restaurant specialising in food from different regions of Africa. It includes navigation to a menu, about page, contact page and reservations page.

The homepage also contains a **Popular Dishes** section featuring dishes such as Egyptian hawawshi, Moroccan chicken rfissa, Nigerian jollof rice and Waakye.

**Technologies:** HTML

📁 [`African Cuisine`](./restaurant)

---

## 📄 3. Resume Website

A personal resume/CV website created using HTML.

The project gave me experience with presenting information in a structured webpage rather than a traditional document.

It helped me practise organising different sections of information and creating a webpage designed around a specific purpose.

**Technologies:** HTML

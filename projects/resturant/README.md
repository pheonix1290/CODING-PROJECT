# 🍛 African Cuisine

## About the Project

**African Cuisine** is a restaurant website I created using HTML.

The website is based around a fictional family-owned restaurant specialising in authentic African cuisine from different regions of Africa.

The homepage introduces the restaurant and displays some of its popular dishes.

## Features

* Navigation bar
* Home page
* Menu page link
* About page link
* Contact page link
* Reservations page link
* Popular dishes section
* Food images
* Image alternative text
* List of reasons to choose the restaurant
* "Back to Top" link
* Footer

The popular dishes section includes examples such as Egyptian hawawshi, Moroccan chicken rfissa, Nigerian jollof rice and Waakye.

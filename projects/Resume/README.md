# 📄 Resume Website

## About the Project

**My Resume** is a personal resume website that I created using HTML.

The purpose of this project was to practise building a webpage that presents personal information in a clear and organised way.

The website is structured like a digital CV and includes information about education, skills, awards, work experience and other personal sections.

## ✨ Features

The website includes:

* Personal introduction and summary
* Profile image
* Education section
* Skills section
* Awards section
* Work experience section
* Hobbies page
* Contact page
* Navigation links to additional pages
* Footer with copyright information

The work experience section includes a Junior Web Development Intern role and information about tasks such as creating webpages, updating content, fixing formatting issues and testing webpages across different browsers.

## 🛠️ Technologies Used

* **HTML5**

## 📚 What I Learned

This project helped me practise:

* Creating a structured HTML document
* Organising information into sections
* Using headings and paragraphs
* Creating ordered and unordered lists
* Adding images to a webpage
* Using `alt` text for images
* Creating links to other webpages
* Using IDs to identify sections
* Organising website files and assets
* Creating a webpage for a specific purpose

# 🌍 Travel Kenya

## About the Project

**Travel Kenya** is a tourism website I created using HTML.

The purpose of the website is to introduce visitors to Kenya and showcase different things they could experience while travelling there.

The homepage includes information and images about Kenyan wildlife, landscapes, beaches, food, culture and sunsets.

## Features

* Navigation links between different pages
* Introduction to Kenya
* Wildlife section
* Nature and landscape section
* Indian Ocean beach section
* Food section
* Kenyan culture section
* Sunset section
* Images with alternative text
* Image captions using `figure` and `figcaption`
* A "Back to top" link
* Footer containing copyright information

## Technologies Used

* HTML5
